## Overview

This is **Project 1** of my Full Stack Development internship at **DecodeLabs**. The task was to build a **fully responsive, modern frontend interface** following the **Mobile-First** approach with semantic HTML5, CSS3, and JavaScript.

The website showcases a digital agency's brand, services, portfolio, testimonials, and contact form  all with smooth animations and a professional aesthetic aligned with **2025 UI/UX trends**.

---

## Project Requirements Met

| Requirement | Implementation |
|-------------|----------------|
| **Mobile-First Design** | CSS written for mobile first, then `min-width` media queries for tablet/desktop |
| **Semantic HTML5** | `<header>`, `<nav>`, `<section>`, `<article>`, `<footer>` used throughout |
| **CSS3 Features** | Flexbox, Grid, CSS Variables, Animations, Transitions, Backdrop-filter |
| **JavaScript** | Custom cursor, word rotator, counter animation, mobile menu, form validation |
| **WCAG Accessible** | High contrast, semantic structure, alt attributes, keyboard navigation |
| **2025 Aesthetics** | Glassmorphism, gradient text, warm color palette (Mocha Mousse + Ethereal Blue) |
| **Responsive Breakpoints** | 480px (mobile), 768px (tablet), 1024px+ (desktop) |

---

## Features

### Hero Section
- Full-screen autoplay video background
- Floating gradient orbs for depth
- Animated word rotator (digital → intuitive → impactful → innovative → meaningful)
- Custom cursor with interactive elements
- Scroll indicator with animation

### Services Section
- 3 service cards (UI/UX Design, Web Development, SEO & Growth)
- Hover effects with icon color change
- Featured card with dark background
- Animated card numbers and arrows

### Portfolio Section
- Grid layout with mixed sizes
- Image overlay on hover
- Project metadata and tags
- Smooth image zoom effect

### Stats Counter
- Animated number counters
- 4 key metrics (Projects, Clients, Satisfaction, Experience)
- Triggers when scrolled into view

### Testimonials
- 3 client testimonials with ratings
- Client photos and details
- Highlight card with quote mark
- Star ratings

### Contact Section
- Two-column layout (form + contact info)
- Form validation
- Animated submit button
- Social media icons

### Responsive Navigation
- Hamburger menu on mobile
- Smooth scroll to sections
- Active link highlighting
- Sticky navbar with blur effect
